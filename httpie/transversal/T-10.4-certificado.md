# T-10.4 — Certificado anti-fraude

> **Transação:** [`T-10.4`](../../transaçõesBackend/transversal/T-10.4-CERTIFICADO.md)  
> **Diagrama:** [`10.4-certificado-emissao.md`](../../foundationDocs/sequenceDiagrams/transversal/10.4-certificado-emissao.md)  
> **IDs:** `{{eventoId}}`, `{{formativaId}}`, `{{certificateHash}}`

Não há `POST /certificates`. A emissão é **efeito colateral** de:

1. `POST /events/{id}/close` — origem `EVENTO`
2. `PATCH /formativas/{id}/review` com `APROVAR` — origem `FORMATIVA`
3. `POST /commissions/caaf/batch-review` `APROVAR`

Em dev, se `CERT_PRIVATE_KEY` / `CERT_PUBLIC_KEY` estiverem vazios, o app gera par **efêmero** na subida (certificados não verificam depois de restart).

---

## Passo 1 — Emitir

Siga [T-F1-009](../F1-aluno/T-F1-009-presenca.md) até o `close`, **ou** aprove uma formativa ([T-F1-006](../F1-aluno/T-F1-006-formativas.md)).

---

## Passo 2 — Listar (aluno)

```
GET {{baseUrl}}/certificates/mine
Authorization: Bearer {{accessTokenAluno}}
```

Copie `hashSha256` → `{{certificateHash}}`. Campo `origem` = `EVENTO` | `FORMATIVA`.

```
GET {{baseUrl}}/certificates/{{certificateId}}/download-url
```

Abra `downloadUrl` no browser (PDF A4). TTL 15 min.

---

## Passo 3 — Verificar público + JWKS

```
GET {{baseUrl}}/.well-known/jwks.json
GET {{baseUrl}}/publico/verificar-certificado/{{certificateHash}}
```

Links: [JWKS](http://localhost:8080/.well-known/jwks.json) · `http://localhost:8080/publico/verificar-certificado/{{certificateHash}}`

**Esperado:** `valido: true`, `verificacaoAssinatura: ED25519_VALID`, `integridadePdf` ok (recomputo SHA-256 do objeto MinIO).

Hash inventado → **404**. Tutorial público: [T-F0-007](../F0-publico/T-F0-006-007-verificacoes-publicas.md).

Outbox: `certificate.issued` — [T-10.1](T-10.1-outbox.md).
