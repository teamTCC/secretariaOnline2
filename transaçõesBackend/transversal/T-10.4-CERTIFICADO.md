# T-10.4 — Emissão de Certificados (Anti-Fraude)

> **Diagrama de referência:** [`foundationDocs/sequenceDiagrams/transversal/10.4-certificado-emissao.md`](../../foundationDocs/sequenceDiagrams/transversal/10.4-certificado-emissao.md)  
> **Status:** ✅ PDF (OpenPDF) + SHA-256 do artefato + Ed25519 + MinIO `.pdf` + verificação pública

---

## Visão Geral

```
POST /events/{id}/close  OU  PATCH /formativas/{id}/review (APROVAR)  OU  CAAF batch-review
    ↓
CertificateIssuerService
    ├── PDF A4 paisagem (OpenPDF)
    ├── hash SHA-256 dos bytes do PDF
    ├── assinatura Ed25519 do hash (nunca UNSIGNED_)
    ├── upload MinIO certificates/{origem}/{id}/{alunoId}.pdf
    └── outbox certificate.issued
```

Se `CERT_PRIVATE_KEY` / `CERT_PUBLIC_KEY` estiverem vazios, [`CertificateKeyInitializer`](../../backend/modules/presenca/src/main/kotlin/br/ufpr/sept/so2/modules/presenca/config/CertificateKeyInitializer.kt) gera um par **efêmero** na subida (dev). Produção deve definir as env vars.

Origens: `EVENTO` (`id_evento`) e `FORMATIVA` (`id_activity`). `id_evento` é nullable (V015).

---

## Verificação pública

```
GET /publico/verificar-certificado/{hash}
```

1. Busca `certificate` pelo hash hex.
2. Rebaixa o PDF no MinIO e recomputa SHA-256 (`integridadePdf`).
3. Verifica Ed25519 sobre os bytes do hash (`verificacaoAssinatura`).
4. `valido` = ambos verdadeiros.

JWKS (`/.well-known/jwks.json`) inclui a chave OKP/Ed25519 (coordenada `x` em base64url).

---

## Checklist

- [x] PDF no MinIO (`application/pdf`), hash do artefato (não de string canônica)
- [x] Sem prefixo `UNSIGNED_` — chave efêmera se env vazio
- [x] Emissão no fechamento de evento **e** na aprovação de formativa (CAAF)
- [x] `GET /certificates/mine` inclui `origem`
- [x] Verificação pública confere PDF + assinatura
