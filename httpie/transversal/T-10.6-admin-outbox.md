# T-10.6 — Admin outbox

> **Transação:** [`T-10.6`](../../transaçõesBackend/transversal/T-10.6-ADMIN-OUTBOX.md)  
> **Diagrama:** [`US-F7-005`](../../foundationDocs/sequenceDiagrams/F7%20—%20Admin/US-F7-005-JOBS-OUTBOX.md)  
> **IDs:** `{{outboxId}}`  
> **Authority:** admin / `system.admin` (confira no Swagger o `@PreAuthorize` exato)

---

## Listar

```
GET {{baseUrl}}/admin/outbox?page=0&size=20
GET {{baseUrl}}/admin/outbox?status=DEAD
GET {{baseUrl}}/admin/outbox/dead
Authorization: Bearer {{accessTokenAdmin}}
```

**Esperado 200** paginado. Meta de lag (se o DTO incluir). Copie um `DEAD` → `{{outboxId}}`.

Para gerar `DEAD` em dev: pare o Mailhog, dispare vários forgot-password e espere retries (lento). Em geral basta inspecionar `PENDING`/`PROCESSED`.

---

## Detalhe

```
GET {{baseUrl}}/admin/outbox/{{outboxId}}
```

**Esperado:** payload + `lastError`. Não compartilhe tokens do payload.

---

## Retry e delete

```
POST   {{baseUrl}}/admin/outbox/{{outboxId}}/retry
DELETE {{baseUrl}}/admin/outbox/{{outboxId}}
```

Retry: `DEAD` → `PENDING` (`SELECT FOR UPDATE`). Delete: descarta o evento. Sem FGAC → **403**.

Fluxo de produção do outbox: [T-10.1](T-10.1-outbox.md).
