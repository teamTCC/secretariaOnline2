## Fase TX — Padrão Outbox (10.1a)

O diagrama especifica que toda ação de negócio que gera notificação deve persistir um `outbox_event` **na mesma transação** da mutação:

```kotlin
// Exemplo: qualquer UseCase que notifica
@Transactional
fun execute(command: DeliberateCommand) {
    requestRepo.updateEstado(id, "DELIBERADA")
    requestEventRepo.save(RequestEventEntity(...))
    
    // INSERT atômico — se o COMMIT falhar, o evento não existe
    outboxRepo.save(OutboxEventEntity(
        eventType = "solicitacoes.deliberated",
        aggregateType = "request",
        aggregateId = id,
        payload = mapOf("idAluno" to aluno.id, "tipo" to requestType.code)
    ))
}
```

> **Nota:** O `TransitionRequestUseCase` atual **ainda não insere** no `outbox_events`. A integração Outbox nos use cases de transição/deliberação é um próximo passo.

## Fase Dispatch — OutboxDispatcher (10.1b)

```kotlin
// OutboxDispatcher.kt
@Scheduled(fixedDelay = 5000)  // a cada 5 segundos
@Transactional
fun dispatch() {
    val now = OffsetDateTime.now()
    val pending = outboxRepo.findPendingEvents(now, PageRequest.of(0, 50))
    
    if (pending.isEmpty()) return
    
    pending.forEach { event ->
        try {
            processEvent(event.eventType, event.aggregateType, event.aggregateId, event.payload)
            outboxRepo.markProcessed(event.id, now)
        } catch (e: Exception) {
            val nextAttempt = now.plusSeconds(backoffSeconds(event.attemptCount))
            outboxRepo.markFailed(event.id, e.message ?: "Erro", nextAttempt)
        }
    }
}
```

### Backoff exponencial para retentativas

```kotlin
private fun backoffSeconds(attempts: Int): Long = when {
    attempts < 3 -> 30L    // primeiras 3 falhas: retry em 30s
    attempts < 5 -> 300L   // 4ª e 5ª: retry em 5 min
    else         -> 3600L  // depois: retry em 1h
}
```

## Como usar o Outbox nos Use Cases

Para integrar o outbox a qualquer use case novo:

```kotlin
// 1. Injetar o repositório
@Service
class MeuUseCase(
    private val outboxRepo: OutboxEventJpaRepository,
    ...
)

// 2. Dentro do @Transactional, ao final da mutação:
outboxRepo.save(OutboxEventEntity(
    eventType = "meu.evento.ocorreu",
    aggregateType = "meu_aggregate",
    aggregateId = entityId,
    payload = mapOf("campo" to valor)
))
// O dispatcher processa em até 5s após o COMMIT
```
