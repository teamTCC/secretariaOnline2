# T-10.5 — Push Notifications via FCM

> **Diagrama de referência:** Outbox pattern — ver [T-10.1-OUTBOX](T-10.1-OUTBOX.md)  
> **Status:** ✅ Firebase Admin SDK integrado. Fallback gracioso sem service account.

---

## Arquitetura

```
Use Case / Controller
    ↓  (atomic TX)
outbox_event  ←  OutboxDispatcher  →  FcmOutboxHandler  →  FirebaseMessaging.send()
                                            ↓ (sem service account)
                                       log.warn("FCM sem credenciais — push ignorado")
```

O `FcmOutboxHandler` vive no módulo **IAM** (pois acessa `device_fcm_token`). Implementa `OutboxEventHandler` e processa eventos do tipo `"push.fcm.send"`. Com `APP_FIREBASE_SERVICE_ACCOUNT_JSON` configurado, envia de verdade; sem ele, loga aviso e não lança exceção.

## Tabela `device_fcm_token`

```sql
CREATE TABLE device_fcm_token (
    id          UUID PRIMARY KEY DEFAULT uuid_generate_v7(),
    id_usuario  UUID NOT NULL REFERENCES usuario(id),
    fcm_token   VARCHAR(500) NOT NULL,
    plataforma  VARCHAR(20) NOT NULL DEFAULT 'ANDROID',
    ativo       BOOLEAN NOT NULL DEFAULT TRUE,
    UNIQUE (id_usuario, fcm_token)
);
```

## Enviar push via Outbox

Para enviar um push a partir de qualquer use case:

```kotlin
// Dentro de @Transactional
outboxRepo.save(OutboxEventEntity(
    eventType = OutboxEventTypes.FCM_PUSH,
    aggregateType = "Usuario",
    aggregateId = idUsuario,
    payload = mapOf(
        "idUsuario" to idUsuario.toString(),
        "titulo" to "Solicitação deliberada",
        "corpo" to "Sua solicitação #2025/0042 foi aprovada.",
    ),
))
```

O `OutboxDispatcher` processa o evento e chama `FcmOutboxHandler.handle()`, que:
1. Busca os tokens FCM ativos do usuário
2. Para cada token, envia via `FirebaseMessaging.getInstance().send(...)`
3. Se o token for inválido (`INVALID_REGISTRATION`, `UNREGISTERED`), desativa-o no banco (`ativo = false`)
4. Se o erro for transitório (ex.: rede), relança a exceção — o dispatcher faz retry com backoff

## FirebaseConfig.kt — Inicialização

```kotlin
// iam/config/FirebaseConfig.kt
@Configuration
class FirebaseConfig {

    @PostConstruct
    fun initialize() {
        val serviceAccountJson = System.getenv("APP_FIREBASE_SERVICE_ACCOUNT_JSON")
        if (serviceAccountJson.isNullOrBlank()) {
            // fallback gracioso: Firebase não inicializado; FcmOutboxHandler detecta e loga aviso
            return
        }
        if (FirebaseApp.getApps().isNotEmpty()) return // já inicializado

        val serviceAccount = ByteArrayInputStream(serviceAccountJson.toByteArray(Charsets.UTF_8))
        val options = FirebaseOptions.builder()
            .setCredentials(GoogleCredentials.fromStream(serviceAccount))
            .build()
        FirebaseApp.initializeApp(options)
    }
}
```

Se `APP_FIREBASE_SERVICE_ACCOUNT_JSON` não estiver definido, o `FirebaseApp` não é inicializado e o `FcmOutboxHandler` detecta isso, loga `warn` e retorna sem enviar — **sem lançar exceção, sem bloquear o dispatcher**.

## FcmOutboxHandler — Implementação Real

```kotlin
// iam/infrastructure/outbox/FcmOutboxHandler.kt
@Component
class FcmOutboxHandler(
    private val fcmTokenRepo: FcmTokenJpaRepository,
) : OutboxEventHandler {

    override fun supports(eventType: String) = eventType == OutboxEventTypes.FCM_PUSH

    override fun handle(event: OutboxEventEntity) {
        if (FirebaseApp.getApps().isEmpty()) {
            log.warn("Firebase não inicializado — push ignorado (configure APP_FIREBASE_SERVICE_ACCOUNT_JSON)")
            return
        }

        val idUsuario = UUID.fromString(event.payload["idUsuario"] as String)
        val titulo    = event.payload["titulo"] as String
        val corpo     = event.payload["corpo"] as String

        val tokens = fcmTokenRepo.findByIdUsuarioAndAtivoTrue(idUsuario)
        tokens.forEach { tokenEntity ->
            try {
                FirebaseMessaging.getInstance().send(
                    Message.builder()
                        .setToken(tokenEntity.fcmToken)
                        .setNotification(
                            Notification.builder()
                                .setTitle(titulo)
                                .setBody(corpo)
                                .build()
                        )
                        .build()
                )
            } catch (e: FirebaseMessagingException) {
                when (e.messagingErrorCode) {
                    MessagingErrorCode.INVALID_ARGUMENT,
                    MessagingErrorCode.UNREGISTERED -> {
                        // token inválido ou expirado — desativa para não tentar de novo
                        tokenEntity.ativo = false
                        fcmTokenRepo.save(tokenEntity)
                        log.info("Token FCM desativado (inválido): ${tokenEntity.id}")
                    }
                    else -> throw e // erro transitório → dispatcher faz retry
                }
            }
        }
    }
}
```
