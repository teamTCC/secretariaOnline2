# T-10.1 — Outbox (observar o efeito das transações)

> **Transação:** [`T-10.1`](../../transaçõesBackend/transversal/T-10.1-OUTBOX.md)  
> **Diagrama:** [`10.1-outbox-notificacao.md`](../../foundationDocs/sequenceDiagrams/transversal/10.1-outbox-notificacao.md)  
> **As-built:** writers usam `OutboxEventPublisher.enqueue`; deep-link termina em `POST /auth/ott`.

Não existe `POST /outbox` de negócio. Você **dispara** um use case e **observa** a linha. Admin: [T-10.6](T-10.6-admin-outbox.md).

Dispatcher: `@Scheduled` ~5 s. Status: `PENDING` → `PROCESSED` | retry backoff → `DEAD` (8 tentativas).

`ops/docker-compose.yml` **não** inclui Mailhog/Mailpit. Confirme o envio pelo status `PROCESSED` e pelo payload. Catcher SMTP em `:8025` é opcional e fora do compose operacional.

---

## Passo 1 — Gerar um evento conhecido

Faça [T-F0-002](../F0-publico/T-F0-002-recuperar-senha.md) (`iam.password_reset_requested`) **ou** abra uma solicitação (`solicitacoes.aberta`) **ou** uma transição com `generateOneTimeToken` (e-mail com `?ott=`).

---

## Passo 2 — SQL

```sql
SELECT id, event_type, status, attempts, last_error, created_at
FROM outbox_event
ORDER BY created_at DESC
LIMIT 20;
```

Copie `id` → `{{outboxId}}`.

---

## Passo 3 — API admin

```
GET {{baseUrl}}/admin/outbox?page=0&size=20
GET {{baseUrl}}/admin/outbox?status=PENDING
Authorization: Bearer {{accessTokenAdmin}}
```

**Esperado 200** paginado. Detalhe:

```
GET {{baseUrl}}/admin/outbox/{{outboxId}}
```

Payload completo (token de reset, JWT OTT, e-mail, etc.). **Não** commite prints com JWT de 1 uso.

Em ~5 s `PENDING` vira `PROCESSED` se o SMTP configurado no backend estiver up. SMTP down: permanece `PENDING` e `attempts` sobe.

Tipos úteis para grep: `iam.password_reset_requested`, `iam.usuario_criado`, `solicitacoes.aberta`, `contato.recebido`, `certificate.issued`, `exports.ready`, `atendimentos.created`.

---

## Passo 4 — Deep-link `?ott=` → `POST /auth/ott`

Se o payload tiver URL `/solicitacoes/{id}?ott=<jwt>` (transição com OTT):

1. Copie o JWT → `{{ottJwt}}`.
2. Troque por sessão: [T-F0-001 Passo 8](../F0-publico/T-F0-001-login.md) — `POST /auth/ott` body `{ "token": "{{ottJwt}}" }`.
3. Esperado **200** + cookies; **segunda** chamada com o mesmo token → **401**.

Não use `POST /auth/login` para consumir o deep-link.
